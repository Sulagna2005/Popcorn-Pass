# PopcornPass — Client

React 19 + Vite frontend for the PopcornPass movie booking app.

## Stack

- React 19, React Router v7
- Tailwind CSS v4
- Axios

## Dev

```bash
npm install
npm run dev
```

Runs on `http://localhost:5173`. API calls to `/api/*` are proxied to `http://localhost:5000` via Vite config.

## Build

```bash
npm run build
npm run preview
```
